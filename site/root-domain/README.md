The root of this GitHub Pages domain. It only holds what has to live at the root:

- `robots.txt` lets every search engine and AI crawler in. Crawlers read `robots.txt` only from the root of a domain, so it cannot live inside a project site.
- `llms.txt` is a short, plain-text summary of the project for AI tools.
- A small landing page that points to the real website.

The project itself, its website and its source are here: <https://github.com/sideeffects69/Magic-Apply-Jobs> and <https://sideeffects69.github.io/Magic-Apply-Jobs/>.

These files are kept in the project repository under `site/root-domain/` and copied here.
